## Behaviour decisions

- Source reader: a parseable reply cut at `finish_reason="length"` is incomplete
  and the chunk is re-read compactly (v0.2.3's rule, documented in
  `docs/research-reliability.md`). Main #9 accepted such replies; its test is
  renamed under the record below.
- Image workflow: the server validates `workflow_json` only when it is new input
  for the active ComfyUI provider. Switching away from ComfyUI with an invalid
  draft is allowed (main #27's escape hatch), and switching back to a stored
  graph keeps it editable: Settings shows the "needs valid JSON" note and blocks
  Save and Test until it is fixed. An invalid graph can never be saved as new
  input for the active ComfyUI provider.
- Provider probes (PR #30): v0.2.3 carried the same fix; its code is kept and
  #30's tests pass against it.
- Preview capability: one signed claim key (`partitioned`), strict bool checks,
  byte-exact cookie passthrough when the claim is missing or malformed.
